# React Movie App

A simple movie discovery app built with React and Vite. Search movies or browse popular titles, view movie details, save favorites, and navigate through paginated results. Favorites are stored in the browser with `localStorage`.

## Tech stack

- React 19
- Vite
- Tailwind CSS 4 and daisyUI
- The Movie Database (TMDB) API

## Run locally

1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env` and add your TMDB v3 API key.
3. Start the development server with `npm run dev`.

Use `npm run build` to create a production build.
